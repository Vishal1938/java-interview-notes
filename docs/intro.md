# Java Interview Notes

My personal collection of Java interview questions, each answered in my own words with **working code**, its **real output**, and the **follow-up questions** interviewers like to ask next.

## How each question is structured

Every page follows the same shape, so it works for quick revision *and* as a full blog post:

1. **Short answer**: the 2–3 line version I'd say in an interview
2. **Detailed explanation**: the "why" behind it
3. **Code example**: runnable, with its actual output
4. **Common follow-ups & pitfalls**: what usually comes next
5. **Key takeaways**: a summary for last-minute revision

> 💡 **Revision tip:** read only the *Short answer* and *Key takeaways* of every page for a fast pass before an interview.
